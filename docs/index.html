dcm4nifi – DICOM Toolkit for Apache NiFi

dcm4nifi is an open-source DICOM and HL7 toolkit for Apache NiFi, enabling seamless DICOM processing, anonymization, compression, and AI-ready data pipelines.

The project brings native DICOM capabilities to Apache NiFi, allowing the creation of scalable and secure medical imaging workflows.

DICOM Processing with Apache NiFi

With dcm4nifi, Apache NiFi can be used to process, route, and transform DICOM data, integrate with PACS systems, and prepare datasets for research and machine learning.

Features

  • DICOM anonymization and pseudonymization
  • DICOM compression and decompression
  • HL7 message processing
  • PACS and radiology system integration
  • AI-ready medical data pipelines
